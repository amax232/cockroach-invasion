Cockroach Invasion - Android project

Fastest way to get an APK (no Android Studio):
1. Create a new GitHub repository and upload everything in this folder (including the hidden .github folder).
2. Open the Actions tab, wait for "Build APK" to finish (about 3 minutes).
3. Open the finished run and download the "CockroachInvasion-apk" artifact. Unzip it to get app-debug.apk.
4. Send the APK to your phone and install it (allow "Install unknown apps").

Android Studio: open this folder, then Build > Build APK(s). The APK ends up in app/build/outputs/apk/debug/.
